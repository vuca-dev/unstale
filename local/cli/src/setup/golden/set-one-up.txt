To read with Jev + OpenAI key, set it up, then run `unstale setup`:

  add JEV_API_KEY=<key> to your shell profile or this repo's .env
  add OPENAI_API_KEY=<key> to your shell profile or this repo's .env (or AI_GATEWAY_API_KEY or
  OPENROUTER_API_KEY)

To read with OpenAI key, set it up, then run `unstale setup`:

  add OPENAI_API_KEY=<key> to your shell profile or this repo's .env (or AI_GATEWAY_API_KEY or
  OPENROUTER_API_KEY)

To read with Jev + Codex plan, set it up, then run `unstale setup`:

  Codex is not logged in. Run `codex login`.
