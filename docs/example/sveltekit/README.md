# Example: SvelteKit

What your agent reads after `unstale init` on [sveltejs/kit](https://github.com/sveltejs/kit) at commit
[`2670d8bba1`](https://github.com/sveltejs/kit/tree/2670d8bba1583a99d8d9fc273085bbcbbb04e9c3), with `@unstale/cli` 0.2.9 on 28 October 2026.

- [onboarding-report.md](onboarding-report.md): the summary. Start with "Leads".
- [review/upgrades.md](review/upgrades.md): full evidence for each upgrade.
- [review/opportunities.md](review/opportunities.md): optional new capabilities at the installed versions.

The files are unedited, except that the path to the local CLI binary is replaced with `unstale`. Findings are
candidates for the agent to check, not confirmed changes.
